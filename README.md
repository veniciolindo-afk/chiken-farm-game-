# Chicken Farm Simulator v0.1

Projeto Godot 4.3 organizado e isolado neste repositório. Protótipo tycoon 3D mobile: compre galinhas, produza e venda ovos e melhore o galinheiro.

## Estrutura

- `scenes/`: cenas do jogo
- `scripts/`: código GDScript
- `docs/`: arquitetura e roadmap
- `.github/workflows/`: builds Web e Android

## Jogar e baixar

- Web (após o primeiro build da `main`): https://veniciolindo-afk.github.io/chiken-farm-game-/
- APK: https://github.com/veniciolindo-afk/chiken-farm-game-/actions

Abra `project.godot` no Godot 4.3 ou superior e pressione F5 para executar.
